# Repository workflow

The user requests that completed project changes be committed and published to
https://github.com/Parth-73/HelpDesk-Bot and kept current during future work.
After implementing and verifying changes, commit and push the relevant source,
tests and documentation. Fetch current remote history first and preserve other
contributors' changes. Never commit private environment files, credentials,
dependencies, model downloads or ignored local assessment archives. Do not claim
a successful push until the remote branch has been verified.

# Actual AI session exports

These JSON files contain visible user/assistant messages exported from actual local Codex session logs whose workspace is this assessment directory or its subdirectories. Hidden analysis, system/developer instructions and tool traces are excluded; API keys and database URLs are redacted. Original logs were not changed. The manifest records session IDs, message counts and original-log hashes. These are real exports, not reconstructed conversations, but cannot establish completeness for chats absent from the local logs.

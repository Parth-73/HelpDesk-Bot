## Contents and provenance

- **HelpDesk bot:** 35 user messages, 72 visible assistant messages/updates and 30 shared file-change records. This snapshot starts with “what can you build” and ends with the question about which session would be restored. It does not include later messages that are absent from that published snapshot.
- **Create Requirement Plan:** 23 user and 23 visible assistant messages, following the shared conversation path. Hidden/non-conversation records, system/tool messages and internal context/reasoning records are not part of this visible-message export.
- Original image references are preserved in the Markdown. The screenshot binaries are not embedded, and their original reference schemes may not render on GitHub; open the shared session to view those images.
- [export_manifest.json](export_manifest.json) records source-response hashes, Markdown hashes, message-text hashes, counts and scope. Every exported original text block was checked for unchanged content and order against the downloaded source.

These are exports from the public shared-session data, not a claim that the ChatGPT client generated these Markdown files or that the snapshots include all private history, tool traces or later conversation updates. No older local sessions or assistant-written work summaries were restored.
